# 🏫 سامانه هوشمند مدیریت کلاس درس، آزمون‌ساز و حضور و غیاب دانش‌آموزان
### Smart Classroom Attendance, Assessment & Eitaa Integration (Version 4.2.0)

این سامانه یک وب‌اپلیکیشن کامل، مدرن و ریسپانسیو مبتنی بر **React 19**، **TypeScript** و **Tailwind CSS** است که به صورت ویژه برای مدارس، دبیران و دانش‌آموزان ایرانی با امکان اتصال مستقیم به پیام‌رسان **ایتا (Eitaa)** طراحی شده است.

---

## ✨ ویژگی‌های برجسته سامانه (Version 4.2.0)

1. **اتصال اختصاصی به گروه‌های چت ایتا به تفکیک درس و کلاس:**
   - امکان تعریف لینک گروه چت ایتا به تفکیک هر درس برای هر کلاس (مثلاً در کلاس هشتم ب: گروه درس *فرهنگ و هنر* جدا، درس *ریاضی* جدا، *علوم* جدا و...)
   - نشانگر وضعیت اتصال زنده برای هر درس همراه با دکمه تست و ورود مستقیم به گروه
   - دکمه ذخیره گروهی لینک‌ها و امکان افزودن دروس سفارشی به کلاس
   - پس از ورود دانش‌آموز به کلاس و درس مربوطه، دکمه بازگشت به گروه چت همان درس به صورت خودکار فعال می‌شود.

2. **پنجره مدیریت کلاس پیشرفته (طرح بهینه‌شده به سبک ویندوز):**
   - باز شدن مشخصات و ابزارهای کلاس (مانند هشتم ب) در پنجره اختصاصی سبک، سریع و ریسپانسیو با کلیک مستقیم روی کارت کلاس
   - نوار عنوان باریک با فونت مناسب، دکمه بستن ضربدر (X) در بالا و پشتیبانی از کلید `Escape` کیبورد
   - افزودن انفرادی یا گروهی دانش‌آموزان با اطلاعات سیدا (کد دانش‌آموزی، نام پدر، شماره موبایل)
   - جستجوی سریع، حذف گروهی و انتقال دانش‌آموزان بین کلاس‌ها

3. **درگاه ورود دانش‌آموز (ورود امن و بدون نیاز به لاگین اولیه برای چت):**
   - انتخاب پایه، کلاس و درس توسط دانش‌آموز
   - ثبت حضور و غیاب لحظه‌ای و هدایت مستقیم به گروه چت ایتای همان درس
   - پنل مشاهده تکالیف و آزمون‌های فعال درس مربوطه

4. **سیستم آزمون‌ساز کلاسی پیشرفته:**
   - **آزمون‌های تشریحی:** ارسال برگه سوال به همراه تصویر، دریافت پاسخ دست‌نویس دانش‌آموز و ثبت بازخورد دبیر
   - **آزمون‌های تستی:** ساخت سوالات چندگزینه‌ای همراه با تایمر زنده و تصحیح خودکار آنی از ۲۰ نمره
   - دکمه‌های پایدار ثبت نمره و بازخورد با تاییدیه وضعیت

5. **پنل مدیریت دبیر (رمز پیش‌فرض: `1234`):**
   - سوابق حضور و غیاب، دفتر نمرات، بازخورد تکالیف، گردونه قرعه‌کشی کلاسی و تایمر معکوس

## 🚀 راهنمای انتقال به گیت‌هاب (GitHub) و استقرار خودکار

پروژه به طور کامل برای استقرار در **GitHub Pages** و سرویس‌های **Netlify** / **Vercel** بهینه‌سازی شده است (`base: './'` و ورک‌فلو آماده GitHub Actions).

### ۱. اتصال مستقیم از محیط AI Studio به گیت‌هاب
از منوی بالای محیط AI Studio (علامت سه‌نقطه یا چرخ‌دنده تنظیمات)، گزینه **Export to GitHub** را انتخاب کنید تا پروژه مستقیماً در اکانت گیت‌هاب شما بارگذاری شود.

### ۲. بارگذاری دستی از طریق Git
اگر پروژه را دانلود کرده‌اید یا می‌خواهید از خط فرمان آن را به گیت‌هاب بفرستید:

```bash
# رفتن به پوشه پروژه
cd classroom-manager

# اضافه کردن آدرس ریپازیتوری گیت‌هاب خود
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git branch -M main

# ارسال تغییرات به گیت‌هاب
git push -u origin main
```

### ۳. فعال‌سازی استقرار خودکار در GitHub Pages
در فایل `.github/workflows/deploy.yml` تنظیمات اجرای خودکار تعبیه شده است:
1. در مخزن گیت‌هاب به تب **Settings** > **Pages** بروید.
2. در بخش **Source**، گزینه **GitHub Actions** را انتخاب کنید.
3. با هر بار `git push` به شاخه `main`، سایت شما به طور خودکار ساخته و در آدرس رایگان `https://<username>.github.io/<repository>/` منتشر می‌شود.

## 💻 نحوه اجرای محلی (Local Development)

```bash
# نصب بسته‌ها
npm install

# اجرای محیط توسعه (پورت ۳۰۰۰)
npm run dev

# بررسی صحت کدهای تایپ‌اسکریپت
npm run lint

# ساخت نسخه پروداکشن (خروجی در پوشه dist)
npm run build
```
