# سامانه هوشمند مدیریت کلاس درس و حضور و غیاب دانش‌آموزان
### Smart Classroom Attendance & Assessment System (Version 4.0.0)

این سامانه یک وب‌اپلیکیشن کامل، سبک و مدرن مبتنی بر React و Vite است که برای مدارس، دبیران و دانش‌آموزان طراحی شده است.

---

## ✨ ویژگی‌های نسخه ۴.۰ (Version 4.0.0)

1. **بهینه‌سازی امنیتی و زیرساخت (GitHub Pages & Netlify):**
   - ساختار کامپایل شده استاتیک و بدون ریدایرکت برای اجرای روان و امن در گیت‌هاب پیجز
   - بارگذاری فوق‌سریع و بدون خطاهای مرورگر

2. **مدیریت پیشرفته کلاس‌ها و دانش‌آموزان:**
   - افزودن لیست پیش‌فرض کلاس **هشتم ب** با تمامی اطلاعات رسمی سیدا (کد دانش‌آموزی، نام پدر)
   - فیلدهای جدید در فرم افزودن دانش‌آموز: **نام پدر** و **شماره موبایل شرکت در کلاس مجازی**
   - ادغام خودکار داده‌ها و سازگاری کامل با حافظه محلی و ابری

3. **پنل آزمون‌ها (آزمون‌ساز کلاسی پیشرفته):**
   - طراحی آزمون‌های تشریحی با بارگذاری عکس برگه سوال و دریافت پاسخ دست‌نویس دانش‌آموز
   - ساخت آزمون‌های تستی چندگزینه‌ای با تایمر زنده و تصحیح خودکار آنی
   - محاسبه و اعلام نمره به دانش‌آموز از ۲۰ (گردشده به بالا) همراه با دکمه‌های پایدار ثبت نظر و نمره (سبز دائمی)

4. **پنل مدیریت دبیر (رمز پیش‌فرض: `1234`):**
   - سوابق حضور، دفتر نمرات، بازخورد تکالیف و ابزارهای کلاسی (گردونه قرعه‌کشی + تایمر معکوس)

## 🚀 راهنمای استقرار در اینترنت (بدون فیلترشکن و بدون خطای ۴۰۳)

### روش اول: انتشار روی Netlify (سریع‌ترین و پایدارترین روش)
1. وارد سایت [Netlify](https://www.netlify.com) شوید و با حساب GitHub خود وارد شوید.
2. روی **Add new site** > **Import an existing project** کلیک کنید.
3. مخزن این پروژه را از اکانت GitHub خود انتخاب کنید.
4. تنظیمات ساخت را بررسی کنید:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. روی **Deploy** کلیک کنید. سایت شما ظرف ۳۰ ثانیه فعال می‌شود و بدون فیلترشکن برای تمام کاربران در ایران کار خواهد کرد.

### روش دوم: انتشار روی GitHub Pages
1. در مخزن گیت‌هاب به بخش **Settings** > **Pages** بروید.
2. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** قرار دهید.
3. با ساخت ورک‌فلو استاتیک Vite، سایت روی آدرس اختصاصی گیت‌هاب شما (`https://<username>.github.io/<repo>/`) فعال می‌شود.

```bash
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه نهایی برای انتشار (پوشه dist)
npm run build
```
